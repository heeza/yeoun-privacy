여운 개인정보 처리방침

시행일: 2026년 11월 20일 (초안 작성 2026-11-11)

운영자: 여운 개발자 (hyuns) · 문의: cosmos6464@gmail.com

여운(이하 "앱")은 예전에 남긴 생각을 다시 만나게 해 주는 개인 기록 앱입니다. 이 처리방침은 앱이 어떤 정보를 어디에 두고, 언제 기기 밖으로 보내는지 그대로 적은 것입니다.

1. 한 줄 요약

  • 회원가입·로그인이 없습니다. 운영자는 서버를 두지 않으며, 여러분이 쓴 기록을 받지도 보관하지도 않습니다.
  • 기록은 이 폰 안(앱 전용 저장소)에만 저장됩니다.
  • 기록이 폰 밖으로 나가는 경우는 단 하나, 여러분이 직접 Gemini를 연결하고 Gemini 질문 버튼을 눌렀을 때뿐입니다.

2. 이 폰 안에만 저장되는 정보

정보내용저장 위치
기록글, 음성 입력으로 받아 적은 글, 책 문장과 출처, 작성 시각앱 전용 데이터베이스(Room, yeoun.db)
하루 한 장 카드이어 보여 준 두 기록의 번호, 질문 문장, 질문에 남긴 반응, 답 기록 번호같은 데이터베이스
설정장면·쉼 소리·알림 시간대 같은 화면 설정, 숨긴 기록 목록앱 전용 설정 파일(SharedPreferences)
Gemini API 키(선택)여러분이 직접 붙여 넣은 키앱 전용 설정 파일
AI 모델 파일(선택)받기를 누른 경우의 작은 AI(약 0.34GB)·깊은 AI(약 2.6GB)앱 전용 저장소
  • 앱의 자동 백업은 꺼져 있습니다(allowBackup=false). 운영자는 위 정보에 접근할 수 없습니다.
  • 앱을 지우면 위 정보가 모두 함께 지워집니다. 기록 하나하나는 앱 안에서 지울 수 있고, 깊은 AI 파일은 설정에서 지울 수 있습니다.

3. 기기 밖으로 나가는 경우

3-1. Gemini 질문 (선택, 기본 꺼짐)

  • 설정에서 여러분 본인의 Google AI Studio API 키로 "Gemini 연결"을 한 경우에만 작동합니다.
  • Gemini 버튼을 직접 누를 때마다, 쓰고 있던 글의 앞 500자와 질문을 만들어 달라는 안내 문장이 Google의 Gemini API(generativelanguage.googleapis.com)로 HTTPS로 전송됩니다.
  • 이 전송은 여러분과 Google 사이의 API 이용 관계에서 이뤄지며, 운영자는 그 내용을 받지 않습니다. Google의 처리 방식은 Gemini API 약관과 Google 개인정보처리방침을 따릅니다(https://ai.google.dev/gemini-api/terms, https://policies.google.com/privacy).
  • Google 서버는 국외(미국 등)에 있을 수 있습니다. 이전 항목: 글 앞 500자. 이전 시점: 버튼을 누를 때. 이전받는 자: Google LLC. 거부 방법: Gemini를 연결하지 않거나 설정에서 연결을 끊으면(키가 지워집니다) 전송되지 않으며, 다른 기능은 모두 그대로 쓸 수 있습니다.
  • 키 확인을 위해 연결할 때 한 번 짧은 시험 문장("'네'라고만 답하세요.")을 보냅니다.
  • Gemini 연결 창을 연 채로 AI Studio에서 돌아오면, 앱은 클립보드에 키 모양(AIza…)의 글이 있는지 확인해 입력칸에 채웁니다. 그 밖의 경우 클립보드를 읽지 않습니다.

3-2. AI 모델 파일 받기 (선택)

  • 작은 AI(Qwen3-0.6B)·깊은 AI(Gemma 4 E2B)는 여러분이 동의하고 "받기"를 눌렀을 때만 Hugging Face(huggingface.co)에서 내려받습니다. 이때 파일 요청만 보내며, 기록 내용은 보내지 않습니다. 일반적인 인터넷 요청처럼 IP 주소 등 접속 정보가 Hugging Face에 남을 수 있습니다.
  • 받은 모델은 이 폰 안에서만 실행되며, 질문을 만들 때 쓴 글은 폰 밖으로 나가지 않습니다.

3-3. Gemini Nano (기기 안 AI)

  • 지원하는 폰에서는 Google의 ML Kit GenAI(Gemini Nano, 시스템의 AICore)로 기기 안에서 질문을 만듭니다. 글은 기기 밖으로 나가지 않습니다.
  • ML Kit SDK는 기능 개선과 오류 진단을 위해 기기·앱 정보, 설치별 식별자, 성능 지표, 오류 코드, 설정 언어 같은 진단 정보를 Google로 보낼 수 있습니다(https://developers.google.com/ml-kit/android-data-disclosure). 기록 내용은 포함되지 않습니다.

3-4. 음성 입력

  • "음성" 탭은 폰에 설치된 음성 인식 앱(예: Google)을 엽니다. 앱은 인식된 글자만 돌려받으며, 녹음 파일을 받거나 저장하지 않습니다. 음성 처리는 해당 음성 인식 앱의 처리방침을 따릅니다.

4. 수집하지 않는 것

광고 ID, 위치, 연락처, 사진, 계정 정보, 결제 정보를 수집하지 않습니다. 광고·분석·크래시 수집 SDK를 쓰지 않습니다.

5. 접근 권한 안내 (정보통신망법 제22조의2)

권한구분목적
알림 (POST_NOTIFICATIONS)선택설정에서 "글쓰기 초대 알림"을 켤 때만 묻습니다. 허용하지 않아도 모든 기록 기능을 쓸 수 있습니다.
인터넷기본선택 기능(모델 받기, Gemini 질문)에만 씁니다.
부팅 완료 수신 · 진동기본알림을 켠 경우 재부팅 뒤 알림 시간을 다시 맞추고, 화면 반응에 짧은 진동을 씁니다.

마이크·저장소·위치·카메라 권한은 요청하지 않습니다.

6. 보관 기간과 파기

기록은 여러분이 지우거나 앱을 지울 때까지 이 폰에만 있습니다. 운영자가 보관하는 개인정보는 없으므로 별도 파기 절차가 없습니다. 문의 메일은 답변 후 1년 안에 지웁니다.

7. 제3자 제공·처리 위탁

운영자는 개인정보를 제3자에게 제공하거나 처리를 위탁하지 않습니다. 3항의 전송은 여러분이 직접 선택한 기능입니다.

8. 아동

앱은 만 18세 이상을 대상으로 하며, 아동(특히 만 14세 미만)을 대상으로 하지 않습니다. Gemini 연결은 Google AI Studio 이용 조건(만 18세 이상)을 따릅니다.

9. 여러분의 권리

기록의 열람·수정·삭제는 앱 안에서 바로 할 수 있습니다. 운영자는 여러분의 기록을 갖고 있지 않으므로, 운영자에게 요청할 정보가 없습니다. 궁금한 점은 아래로 연락해 주세요.

10. 안전성 확보 조치

기록과 설정은 Android 앱 전용 저장소에 두어 다른 앱이 읽을 수 없습니다. 외부 전송은 HTTPS로만 합니다. Gemini 키는 요청 주소가 아니라 헤더로 보냅니다.
