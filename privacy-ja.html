余韻（Yeoun）プライバシーポリシー

施行日：2026年11月20日（草案作成 2026-11-11）

運営者：余韻（Yeoun）開発者（hyuns） · お問い合わせ：cosmos6464@gmail.com

余韻（Yeoun、以下「本アプリ」）は、かつて残した考えと再び出会えるようにする、個人向けの記録アプリです。このプライバシーポリシーは、本アプリがどの情報をどこに置き、いつ端末の外へ送るかを、そのまま記したものです。

1. 要約

  • 会員登録やログインはありません。運営者はサーバーを置いておらず、皆さまが書いた記録を受け取ったり保管したりすることもありません。
  • 記録は、このスマートフォン内（アプリ専用の保存領域）にだけ保存されます。
  • 記録がスマートフォンの外へ出るのは、皆さまご自身が Gemini を接続し、Gemini 質問ボタンを押したときだけです。

2. このスマートフォン内にだけ保存される情報

情報内容保存場所
記録文章、音声入力で書き取った文章、本の一文とその出典、作成日時アプリ専用データベース（Room、yeoun.db）
一日一枚のカード並べて表示した二つの記録の番号、質問文、質問への反応、答えの記録番号同じデータベース
設定場面・休息の音・通知の時間帯などの画面設定、非表示にした記録の一覧アプリ専用の設定ファイル（SharedPreferences）
Gemini API キー（任意）皆さまご自身が貼り付けたキーアプリ専用の設定ファイル
AI モデルファイル（任意）「ダウンロード」を押した場合の、小さな AI（約 0.34GB）・深い AI（約 2.6GB）アプリ専用の保存領域
  • アプリの自動バックアップはオフです（allowBackup=false）。運営者は上記の情報にアクセスできません。
  • アプリを削除すると、上記の情報はすべて一緒に削除されます。記録はアプリ内で一件ずつ削除でき、深い AI のファイルは設定から削除できます。

3. 端末の外へ出る場合

3-1. Gemini 質問（任意、初期状態ではオフ）

  • 設定で、皆さまご自身の Google AI Studio API キーを使って「Gemini を接続」した場合にだけ動作します。
  • Gemini ボタンを押すたびに、書いていた文章の先頭 500 字と、質問を作ってほしい旨の案内文が、Google の Gemini API（generativelanguage.googleapis.com）へ HTTPS で送信されます。
  • この送信は、皆さまと Google との API 利用関係において行われるものであり、運営者はその内容を受け取りません。Google の取り扱いは、Gemini API 利用規約および Google プライバシーポリシーに従います（https://ai.google.dev/gemini-api/terms、https://policies.google.com/privacy）。
  • Google のサーバーは国外（米国など）にある場合があります。移転する項目：文章の先頭 500 字。移転の時点：ボタンを押したとき。移転先：Google LLC。拒否する方法：Gemini を接続しないか、設定で接続を解除すれば（キーは削除されます）送信は行われず、ほかの機能はこれまでどおりすべて使えます。
  • キー確認のため、接続時に一度だけ短い確認用の文を送ります。
  • Gemini の接続画面を開いたまま AI Studio から戻ると、本アプリはクリップボードにキーの形式（AIza…）の文字があるかを確認し、入力欄に入れます。それ以外の場合にクリップボードを読むことはありません。

3-2. AI モデルファイルのダウンロード（任意）

  • 小さな AI（Qwen3-0.6B）・深い AI（Gemma 4 E2B）は、皆さまが同意して「ダウンロード」を押したときにだけ、Hugging Face（huggingface.co）からダウンロードします。このとき送るのはファイルのリクエストだけで、記録の内容は送りません。通常のインターネット通信と同様、IP アドレスなどの接続情報が Hugging Face に残ることがあります。
  • ダウンロードしたモデルはこのスマートフォン内でのみ実行され、質問を作るときに使った文章がスマートフォンの外へ出ることはありません。

3-3. Gemini Nano（端末内 AI）

  • 対応しているスマートフォンでは、Google の ML Kit GenAI（Gemini Nano、システムの AICore）により、端末の中で質問を作ります。文章が端末の外へ出ることはありません。
  • ML Kit SDK は、機能改善とエラー診断のために、端末・アプリ情報、インストール単位の識別子、性能指標、エラーコード、設定言語などの診断情報を Google へ送ることがあります（https://developers.google.com/ml-kit/android-data-disclosure）。記録の内容は含まれません。

3-4. 音声入力

  • 「音声」タブは、スマートフォンに入っている音声認識アプリ（例：Google）を開きます。本アプリが受け取るのは認識された文字だけであり、録音ファイルを受け取ったり保存したりすることはありません。音声の処理は、その音声認識アプリのプライバシーポリシーに従います。

4. 収集しないもの

広告 ID、位置情報、連絡先、写真、アカウント情報、支払い情報は収集しません。広告・分析・クラッシュ収集の SDK は使いません。

5. アクセス権限のご案内（韓国・情報通信網法 第22条の2）

権限区分目的
通知（POST_NOTIFICATIONS）任意設定で「書くことの招待通知」をオンにしたときにだけ伺います。許可しなくても、記録の機能はすべて使えます。
インターネット標準任意機能（モデルのダウンロード、Gemini 質問）にだけ使います。
起動完了の受信 · 振動標準通知をオンにしている場合、再起動のあとに通知時刻を再設定し、画面操作への短い振動に使います。

マイク・ストレージ・位置情報・カメラの権限は求めません。

6. 保管期間と消去

記録は、皆さまが削除するかアプリを削除するまで、このスマートフォン内にだけあります。運営者が保管する個人情報はないため、別途の消去手続はありません。お問い合わせのメールは、返信後 1 年以内に削除します。

7. 第三者提供・処理の委託

運営者は、個人情報を第三者に提供したり、処理を委託したりしません。第3項の送信は、皆さまご自身が選んだ機能です。

8. 子どもについて

本アプリは満18歳以上を対象としており、子ども（とくに満14歳未満）を対象としていません。Gemini の接続は、Google AI Studio の利用条件（満18歳以上）に従います。

9. 皆さまの権利

記録の閲覧・修正・削除は、アプリの中ですぐに行えます。運営者は皆さまの記録を持っていないため、運営者に請求できる情報はありません。ご不明な点は、下記までご連絡ください。

10. 安全性の確保のための措置

記録と設定は Android のアプリ専用保存領域に置き、他のアプリが読めないようにしています。外部への送信は HTTPS のみで行います。Gemini のキーは、リクエストのアドレス（URL）ではなく、ヘッダーで送ります。
